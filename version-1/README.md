# PosturePro Version 1.0

### Laptop-based fall detection prototype developed as the first version of PosturePro.

## Overview

This version performs real-time fall detection using a webcam and microphone on a Windows PC or laptop. It uses MediaPipe Pose estimation, Kalman filtering, and offline voice recognition to detect falls and generate alerts.

## Requirements

- Python 3.9+
- Webcam
- Microphone

**See "requirements.txt" for all dependencies.**
